📋 Sample Templates

ℹ️ How to Use

📥 To Import:
  1. Select the data type you want to import
  2. Choose file format (CSV or JSON)
  3. Select your file
  4. Optionally check "Replace existing data"
  5. Click "Import Data"
📤 To Export:
  1. Select which data to export (or "All Data")
  2. Choose format (CSV or JSON)
  3. Click "Export Data"
  4. File will download automatically
📋 CSV Format:
icon_emoji,stat_number,stat_label,display_order
👥,2500+,Total Students,1
📚,45+,Expert Teachers,2
🏆,150+,Achievements,3
📋 JSON Format:
[
  {
    "icon_emoji": "👥",
    "stat_number": "2500+",
    "stat_label": "Total Students",
    "display_order": 1

  {

    "display_order": 2
  }
