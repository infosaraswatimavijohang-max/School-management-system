# 📋 About Page Admin - Quick Reference Card

## 🚀 Getting Started

1. **Login** to admin portal as `admin` or `staff` user
2. **Navigate** to "About Page Management" section
3. **Choose** a section (Stats, Vision, Timeline, etc.)
4. **Click** "+ Add New..." button
5. **Fill** the form
6. **Save** - Changes appear instantly on public About page!

---

## ✏️ How to Edit

1. Go to the section you want to edit
2. Find the item in the table
3. Click **✏️ Edit** button
4. Change values in the form
5. Click **Save**
6. Refreshed automatically!

---

## 🗑️ How to Delete

1. Find the item you want to delete
2. Click **🗑️ Delete** button
3. Confirm when asked
4. Item is removed immediately

---

## 📸 Getting Photo URLs

### Method 1: Use Direct URLs
- Google Drive: Get sharing link, convert to direct link
- Imgur: Right-click image → Copy image address
- Your own hosting: Get full URL to image file

### Method 2: Photo URL Format
```
https://example.com/images/photo-name.jpg
```

Make sure it:
- Starts with `https://`
- Points to actual image file
- Is publicly accessible
- Works when clicked directly

## ✅ Best Practices

### DO:
✅ Keep descriptions short and clear
✅ Use emojis relevant to content
✅ Maintain consistent ordering
✅ Add complete information
✅ Test photo URLs before saving
✅ Review content for spelling/grammar

### DON'T:
❌ Leave required fields empty
❌ Use broken photo links
❌ Add duplicate content
❌ Use very long descriptions
❌ Ignore display order
❌ Delete without confirmation

## 🔍 Verification Checklist

Before **Saving**, verify:

- [ ] All required fields filled
- [ ] Photo URL is correct (if applicable)
- [ ] Email is valid format (if applicable)
- [ ] Display order is logical
- [ ] Spelling/grammar correct
- [ ] Emoji is appropriate
- [ ] Data is accurate

---

## ⚠️ Important Notes

1. **Changes are instant** - They appear on public About page immediately
2. **Soft delete only** - Deleted items can be restored if needed
3. **Order matters** - Lower numbers appear first
4. **Photos need URLs** - Not file uploads, use links
5. **No duplicates** - Each entry should be unique
6. **Active status** - Only "Active" items show on public page

---

## 🆘 If Something Goes Wrong

### Problem: Form won't save?
- Check browser console for errors
- Verify all required fields are filled
- Check photo URL is valid
- Try refreshing page

### Problem: Changes not appearing?
- Wait 2-3 seconds for refresh
- Refresh the About page (Ctrl+F5)
- Check if item is marked "Active"
- Clear browser cache

### Problem: Photo not showing?
- Verify photo URL is correct
- Check if link is public/accessible
- Try a different image
- Check browser console errors
